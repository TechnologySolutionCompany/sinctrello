# Prévias do fluxo Trello

Estas imagens foram renderizadas pelo aplicativo em um teste WPF com o TrelloReadService real e respostas HTTP controladas. Conta, quadro, IDs, credenciais e cards são fictícios. As telas não comprovam acesso ao Trello nem autorização da conta do usuário.

- `01-connection-dialog.png`: fluxo de API key e autorização de leitura, antes de informar dados.
- `02-connected-settings.png`: estado resultante da validação e leitura das respostas de teste.
- `03-loaded-card.png`: card filtrado pelo membro e ação de abrir o link habilitada.
